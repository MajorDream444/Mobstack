# Host Adapters

Adapters translate the MobStack run contract into host-native instructions.

- **Claude Code:** sustained repository implementation and branch work.
- **Claude Cowork:** operational files, research intake, and administrative workflows.
- **Codex:** engineering, evidence reconciliation, audits, tests, and hardening.
- **Google AI Studio:** rapid prototypes and one-shot demonstrations.

Every adapter preserves permissions, prohibited actions, evidence classes, human gates, source references, and receipt output. A generated claim never becomes canonical merely because a build succeeds.
