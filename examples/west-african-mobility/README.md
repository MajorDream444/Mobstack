# West African Mobility Canary

The West African Mobility OS is MobStack's first real workload.

This directory contains no copied claims, decision registers, counterparties, prices, or field records. A run pins the Industry OS repository and commit, loads its instructions and source-of-truth protocol, and treats that repository as authority for mobility facts.

The first acceptance test is whether MobStack blocks unsupported verified claims, reused decision IDs, premature pricing or deposit language, invented supplier authority, and realistic synthetic records presented as operational truth.
