# Foundation Gates

1. **truth-gate** — evidence classes, provenance, conflicts, and canonical IDs.
2. **language-gate** — unsupported authority, pricing, orders, partnerships, and readiness.
3. **authority-gate** — the person or organization authorized to decide or represent.
4. **capital-gate** — deposits, investment, returns, escrow, credit, and payment activity.
5. **ownership-gate** — measured contribution versus legally created ownership.

Agents raise gates. Named humans decide them. Every decision emits a receipt.
