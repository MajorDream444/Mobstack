# Contract and Safety Tests

Foundation acceptance cases:

- reject a run without a pinned workload commit;
- reject an agent without a MOB and human owner;
- reject a gate decision without a named human;
- support PASS, HOLD, REDIRECT, and STOP only;
- preserve OPEN and CONFLICT states;
- block external prices sourced from assumptions or conflicts;
- block deposit and investment activity without an approved capital gate;
- distinguish synthetic demonstration records from evidence;
- prevent an Industry OS from silently rewriting HAMAL doctrine;
- require a receipt for every completed run.

Executable tests will be added when the runtime language and package boundary are selected. This is a specification, not a claim of implemented enforcement.
